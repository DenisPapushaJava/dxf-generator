# Лицензии и распространение

Собственный код DXF Generator распространяется под [MIT](../LICENSE), по решению автора от 20 октября 2026 года. Лицензия приложения не заменяет условия Qt и других сторонних компонентов.

Windows portable EXE статически использует Qt Core/Gui/Widgets и Windows platform plugin на условиях LGPLv3. QXlsx используется на условиях MIT; его изменённые исходники, LICENSE и описание исправлений сохранены в `third_party/qxlsx`.

В справке «?» доступны заметное уведомление об использовании Qt и кнопка «Лицензии…» с полными текстами и атрибуциями. В релизе рядом с EXE публикуется архив `dxf-generator-v0.2.0-sources.zip`: исходники приложения и QXlsx, полный немодифицированный QtBase 6.10.3 из commit `7ddbc87d8e14ce51d2957ea72d0a6077593d5ff4`, лицензии/атрибуции и инструкции сборки. Файл `source-manifest.json` фиксирует SHA-256 Qt-архива и commit приложения.

Инструкции в [rebuilding.md](rebuilding.md) и ручном Windows workflow позволяют пересобрать приложение и перелинковать его с изменённым Qt. Для запуска своего EXE не требуются ключ установки, разрешение сервера или подпись издателя. Архив материалов не нужен для обычного запуска portable EXE.

Уведомления Qt получены скриптом `scripts/generate_legal_notices.py` из закреплённых исходников, включая полный каталог `qt_attribution.json` и соответствующие тексты лицензий. Каталог содержит также инструменты/компоненты Qt, отключённые в конфигурации приложения; исходники не усечены.

Официальные условия: [Qt LGPL obligations](https://www.qt.io/development/open-source-lgpl-obligations). Конкретные тексты лицензий включены в материалы релиза. Статическая поставка использует вариант предоставления соответствующего исходного кода и кода приложения для пересборки.

Python и ezdxf используются только при разработке и в поставку EXE не входят. GPL-библиотека libdxfrw не подключена.
